# Handoff Bundle - MiniGame Studio v3.0

## 視覺資產清單 (Visual Asset Manifest)

本資料夾包含「博論魔王現代化冒險」的所有核心視覺資產，設計邏輯嚴格遵循「一人公司」之 HCI 降噪與友善人機互動原則。

- **`main-scene.png`**：遊戲主畫面。
    - **風格**：卡通風、橘黃色調。
    - **佈局**：遊戲演繹區佔 60%，UI 決策區佔 40%，確保「判斷力 (Judgement)」有足夠的留白空間。
- **`player-character.png`**：玩家角色。
    - **形象**：卡通風、戴著眼鏡的學生（學術宅風格），體現「面對困難時的冷靜」。
- **`monster.png`**：要對抗的「怪」。
    - **形象**：**「博論魔王」**。外型是一本巨大的精裝書（論文本身），帶有逗趣的表情，不具威脅性但富有「性格 (Character)」。
- **`ui-elements.png`**：核心互動組件。
    - 包含：開始按鈕 / 計分顯示 / 暫停按鈕 / 結束按鈕。
- **`ending-screen.png`**：結尾畫面。
    - **佈局**：中間留有寬敞的訊息 Box，用於顯示給學弟/朋友的最後鼓勵。
- **`landing-page-mockup.png`**：服務推廣主頁模型。
- **`commission-form-mockup.png`**：客戶委託表單介面模型。

## 風格指引 (Style Guide)

為了傳達「社團/學術傳承」的溫暖感，我們定義了以下視覺規範：

### 1. 配色方案 (Color Palette)
- **主色 (活力與溫暖)：** `#F4A742` (橘黃色)
- **底色 (靜謐與紙張感)：** `#F5F0E8` (米白色)
- **重點色 (沈穩與專業)：** `#6B4423` (深棕色)

### 2. 字體規範 (Typography)
- **選用字體：** 圓潤無襯線體 (Rounded Sans-serif)，建議使用 **Nunito** 或類似字型。
- **意義：** 圓潤的字體能有效消解「論文」與「幹部責任」帶來的尖銳壓力感。

### 3. 整體調性 (Tone & Mood)
- **核心關鍵字：** 友善、有趣、不刻意追求過度精緻 (Friendly, Fun, Authentically Human)。
- **設計哲學：** 採用帶有手繪感的卡通風格，讓使用者感到「這是一個可以親近的工具」，而非冰冷的自動化系統。

## 使用建議
開發部門 (Gemini CLI) 在實作時，應優先確保 UI 區塊 (40%) 的橘黃色系具備良好的對比度，並利用深棕色進行關鍵資訊的「3 秒標示」。
